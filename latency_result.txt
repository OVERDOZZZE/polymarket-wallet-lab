HOW TO READ THIS
==============================================================================
* Spike race + cross-correlation already contain network + venue reaction + feed delay,
  because every arrival is stamped on your VPS clock. That is the 'net speed'.
* A feed 50 ms closer but 51 ms slower to react shows up as +1 ms here. Nothing to add up.
* Chainlink being hundreds of ms behind is expected: it aggregates several venues first.
  It matters because the 5-min markets RESOLVE on it, not because it is a fast signal.
* Run for several minutes, ideally during busy hours, and repeat at a different time.
